# My setup

The Garden's "diff" and "integrate" prompts ask the agent to read this file.
Copy it to ~/.config/playbook-herdr-garden/setup.md and write your own.
Keep it short: what you use, and where it lives. The agent reads the places
you name here and compares the picked item with them.

- Terminal: Herdr, one tab per project.
- Agents: Claude Code and Codex, each started in a Herdr pane.
- Skills: ~/.claude/skills, one folder per skill.
- Plugins: the list that `claude plugin list` prints.
- Languages: Python 3.11 or newer, and TypeScript.
- Rules: nothing is installed without my yes, and every install has an undo.
